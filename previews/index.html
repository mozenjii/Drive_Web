Personalising a preview

Each file is fully self-contained — one HTML document, no build step, no dependencies. Near the top of the <body> there is a single const SCHOOL = { … } block. Change the school name, city, county, phone, DMV licence number, years, review count and instructor names, and every heading, link, footer, page title and service-area chip updates automatically.

That is the only block you edit per prospect. Budget about two minutes per personalised preview.

Placeholder content — replace before sending

Every school name, licence number, price, statistic, review and instructor in these files is invented for demonstration. Before sending a preview to a real business, replace the licence number and figures with that school's own — or delete them. Do not attribute invented reviews or statistics to a real named business.
